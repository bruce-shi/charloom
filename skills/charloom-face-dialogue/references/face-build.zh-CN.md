# 在原始扫描面上绑定表达式

[English](face-build.md) · 简体中文

使用原始的静态扫描图、经过校准的引导图、唇纹图以及已审核的源-三角形分配图。MakeHuman模板提供了拟合的身体和骨骼结构。扫描图则包含了可见的头部、面部特征、UV坐标以及纹理。

## 检查并标记来源

从正面和斜侧面渲染脸部，逐个检查连通组件。区分画在贴图上的眼睛、开放的眼部贴片、闭合眼球、睫毛和口内碎片。在标定源图上描闭唇线及上下睑缘。唇线文件保存文件 SHA-256，guide 和 transfer 记录保留流程生成的 `source_hash`。两个哈希由当前工具分别产生。

对于明确的赋值，配置JSON将传输目录的basename映射到其设置中。将传输报告的`source_hash`放在`face_atlas.source_hash`下。`face_atlas.parts`条目是审核半开源三角形范围。

- `skin` 选择连接的面部皮肤和颈部表面。
- `face_overlay` 保留了属于可见面部的开放纹理贴片。它们具有相同的表面表情。
- `eye_l`和`eye_r`分别代表了实际的眼球结构。在使用这些参数之前，请先确认它们的几何形状和旋转位置。
- 单独的眉毛使用分割审查的`brow`分配。使用`internal`检查过时的内部片段，以便将其从服装输出中移除。

对于绘制或封闭扫描的面部，请使用以下扫描表面入口点。它细分了观察到的面部三角形，分割了描摹的唇部接缝，保留了中性表面和UV插值，并添加了面部形态目标。其口腔边缘遵循实际的唇部分割线。头部连接部分则复用了校准后的颈部组件。

## 构建并验证

在检查器中，将 `PY` 设置为CV解释器，并安装观看者已锁定的Bun依赖项。将 `CHARLOOM_TRANSFER_DIR` 设置为已完成的传输的父级，将 `CHARLOOM_HEAD_DIR` 设置为新的输出父级，将 `NAME` 设置为传输的basename。传输必须包含其匹配的口型轨迹和嵌入的 `walking` 片段。

```sh
export CHARLOOM_TRANSFER_DIR CHARLOOM_HEAD_DIR
export CHARLOOM_CV_PYTHON="$PY"
"$PY" scripts/roster/bind_scan_head.py "$NAME" --config "$CONFIG"
bun scripts/roster/embed-clips.ts "$NAME"
bun scripts/roster/verify-face.ts "$NAME"
```

在不需要明确指定源部分赋值时，省略`--config`。对于集成的 Blender 工作流程，将`head_binding="scan-surface"`传递给`api.build_character`。工作节点 CLI 接受`--head-binding scan-surface`。

检查 `report.json` 以查找 `route=scan_surface_binding` 和原始源路径及哈希值。检查 `controls.json` 以获取测量得到的中性面部表面距离与原始扫描数据之间的关系。`animated-checks.json` 涵盖了最终裸体和穿着GLB的情况。

在画廊中同时查看两个导出文件。检查静止状态下的眼睑、眨眼时的眼睑以及完全睁开眼睛时的眼睑。检查M/B/P处的完整唇缝、F/V处的下唇、最大开口状态下的口腔内衬，以及通过头部转动观察到的颈部。记录源对应关系、几何检查以及实际视觉观察结果。在比较不同层次时，使用相同的剪辑时长和摄像机。

通过 `volume_head.py` 和 `head_binding="anatomical"`，可以获取解剖学面部组件，适用于明确选定的重建工作，包括适配的眼睛球形和牙齿组件。在构建之前，请根据源结构和任务要求选择相应的路径。

若切颈报告显示默认切面在已选原头表面下方，先确认 `face_atlas.parts.skin` 的隔离图含真正的颈皮肤，再在实际工作坐标中量出有完整颈环、且低于嘴角的水平截面。在同一角色配置中用 `plane_y_m` 指定该高度，检查生成的头颈接缝和转头帧。中性表面偏差检查只对来自原扫描的表情三角面执行；人工颈桥与封口仍随头骨运动。眨眼同时查看闭眼近景、眉形与实际导出动作中的眼裂，闭唇与 F/V 则在说话片段中逐帧复查。

若高领衣物在后颈高、下巴处低，水平切面会把衣料带到裸身上。隔离原头壳，沿实际露肤边界在左右颈侧和后颈各标一个工作空间点。在角色配置里用 `neck_plane_points_m` 写三组 `[x,y,z]` 米坐标，用 `plane_y_m` 指定保留颈部原始壳体的参考高度。脚本按这三个点定切面，保留上方原头表面，固定两端边界，平滑模板颈部到肩的过渡。下方接缝从裸身肤色图取色。用裸身正侧背和纯色材质查看整个颈部，再在同一转头帧对比衣领、下巴与后脑勺。记录实际选点和原图依据。

**穿衣版的高领**。在同一正面转头或闭眼帧，依次隐藏 `body`、`fitted_head`、`FaceSurface` 和实际衣领，定位覆盖衣料的肤色锯齿。若原扫描的露肤颈带完整、与高领共用可辨认的几何边界，且衣服覆盖了下方模板颈面，可在已配置三点切面的角色项中加 `dressed_neck_from_scan: true`。穿衣版会沿切面取回原扫描颈带及其 UV，核对原衣领边点，使用衣领已有的位置和权重衔接到头骨。裸身仍使用前一步的光顺颈部。检查报告的共享边点数及原颈带面数，并在正面闭眼、侧面行走、转头与最大张口处复查。低领、露肩或颈部边界不完整时，需要先确定真正可见的皮肤范围。

穿衣身体被高领和其他衣物完全遮住时，可以省略这一层没有可见三角面的身体 mesh；另行交付含完整身体的裸身 GLB 和可编辑场景。启用原颈带的穿衣版会在 `controls.json` 中记录 `dressedNeck`，由 `verify-face.ts` 在实际动作中核对可见的原头、面部、颈带与衣领对应点。读取两层各自的 `neckMaxMm`，再检查穿衣近景。
