# 臂长与臂部到腰部的间隙

[English](surface-measurements.md) · 简体中文

在原始扫描图和**导出皮肤**中，分别测量每侧的长度。记录肩部到肘部、肘部到腕部的长度，以及腕部到可见指尖的长度之和，还有从肩部到指尖的垂直距离，以及指尖的水平偏移量。在表面上定位手的端点。腕关节、手掌中心或末端骨可以位于指尖的较高位置。在带有手套的扫描图中，确定哪些指尖是可见的，并将手套作为表面参考。当上臂和前臂的数据一致，但端点不一致时，检查腕部到手部的映射关系。分别测量手掌长度、手掌周长、手指展开角度和方向。在重新导出后，检查轮廓和腕部的过渡情况。

在注册的正面和其他出口处，选择位于下肋、肚脐和腰部的匹配高度。在每个高度，从躯干的外缘到同侧手臂的内缘进行水平测量。在出口处使用三角形平面截面，隔离手臂和躯干的面。将这一间隙以毫米为单位与肢体长度进行比较。对于与姿势相关的间隙，重现所报告的片段和时间，相对于骨盆测量高度，并在整个周期中再次测量。静态的A姿势和行走姿势的肩膀角度不同。如果其他部分一致，但移动的手臂悬挂得较宽，请检查该片段中的肩膀旋转。在调整摆动后，在整个周期中测试前臂和手相对于腰部、髋部和大腿的位置；在画廊中检查正面和斜侧视图。

### 测量并测试导出的皮肤

在角色已注册的轮廓点图上标出双侧测量点。在皮肤可见的位置使用原始扫描图。标出肩部尖端、外肘部、手腕、指尖、髋部、外膝部和外踝关节。在前视图中确定宽度和中心线，并在校准的侧面图像中确定相应的矢状位置。在相反侧或根据扫描几何形状确定遮挡情况。记录在手套、袖子、盔甲或裤子下的任何推断出的跨距。在装配前定义手腕参考点和近端腿部端点。

1. 沿着肩峰从肘部外侧到手腕外侧，以及从髋部外侧到踝关节外侧的线条进行绘制。在表面沿线进行采样，包括所有弯曲部分。将这些路径在测量图表上标出，并计算出它们的**3D**线段长度。将肩-肘-腕和髋-膝-踝关节链作为独立的解剖测量单位。记录手腕到指尖以及肩到髋部的3D尺寸。将高度差异分别标记为垂直偏移。对于实际的服装图案，应将要求的袖口、腰带、下摆和宽松度与这些身体测量值分开记录。
2. 在拟合过程中使用每个参考路径。分别比较各个部位，并检查肩部、肘部、膝盖和脚踝，以及手掌宽度和指尖。一个匹配的总值可以掩盖任一部分的误差。如果参考路径只提供一个视图，则记录投影长度和缺失的深度。
3. 在最终皮肤部分，标识出相应的位置。使用三角形ID和重心坐标来绑定可复现的路径。对于解剖学部位，可以使用网格衍生中心或顶点绑定。即使适配的皮肤与这些关节的位置发生偏移，复制的骨骼结构仍能保持原有的骨骼长度。
4. 使用CV解释器运行`scripts/mh-check-lengths.py GUIDE POINTS.json EXPORTED.glb --out REPORT.json --tolerance-mm T`。输入字段在脚本中有说明。为地标提供前视像素和3D证据，以及有序的表面路径。从相机分辨率中选择T，标记不确定性和导出比例。读取每个目标、实际值和带符号的残差。对先前文件和替换文件进行相同的审查，以确认是否捕捉到报告中的不匹配问题。在画廊中重新打开精确的导出文件，并检查轮廓、背面、行走和隔离设备。

**投影跨度的可比性**。把同一配准相机下渲染的最终裸身轮廓叠在量体图上。前视足部横线可以同时穿过不同前后位置的脚趾和脚跟；侧视掌缘可能包含向外张开的拇指。分清整段投影的边缘与一个局部平面的截面。将标为掌主体的参考区域与导出手掌作比较时，逐方向检查拇指是否进入网格截面。颈根斜截面也可能横跨下颌和斜方肌。记录实测差值、面片选区和不一致的解剖边界。遇到这种情况，另列同一相机中的轮廓差，并保留局部厚度或宽度项待有可辨认的同站端点后复核。
