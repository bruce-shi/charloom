# 拟合并复测 MakeHuman 身体

[English](mh-body-fitting.md) · 简体中文

所有观测都采用扫描的工作坐标系。拟合前为左右两侧的每个解剖站位分别保存目标值。可见皮肤直接测原扫描。被衣物遮挡时，将参考图配准到相同的姿势、视角、尺度和解剖高度。记录估计值及其容差。[身体测量技能](../skills/charloom-body-measure/SKILL.zh-CN.md)

从完整身体开始拟合。比较正、侧、斜视图的轮廓以及实际截面的宽度和深度。单侧抬臂时，检查胸廓形状和三角肌到上臂的过渡。手腕除了量到指尖的距离，还要检查手掌朝向。[身体适配技巧](../skills/charloom-body-fit/SKILL.zh-CN.md)

在导出的裸身和穿衣版上重复测量。出现穿插时，定位受影响的三角面，并在静止和运动状态下检查局部修改。除相交数量外，还要复查轮廓和组织厚度。报告中分开记录闭合截面、局部观测和缺失视图。 [表面测量定义](../skills/charloom-body-measure/references/surface-measurements.zh-CN.md)
